# CONTENT TEMPLATE — AP SI study material (v1, locked)

## A. Lesson page template (website articles.js entry)
Fields: id, crumbs, kicker, title, meta, content (HTML), questions[].

Content order (provision-first, never facts-first):
1. **Literal provision** — paraphrase the exact rule simply.
2. **Plain meaning** — teach as if first-time student.
3. **Why it exists** — problem it solves.
4. **Analogy** — one everyday comparison (no jargon).
5. **Real-life example** — visualisable Indian scene.
6. **Connections** — evolution, amendments, cases, exceptions, AP SI relevance.
7. **Memory hook + cracking approach** — 60-second method.

Boxes: blue = concept/foundation, green = trusted rule/takeaway, amber = exceptions, takeaway div at end.
Rules: simple teacher English; zero assumed knowledge; every claim exam-actionable; verified facts only (cite year/court/amendment); never present pending/flux as settled (Sabarimala, Governor assent, 106th operation); no bare one-liners; no internet-copy definitions.

## B. Quiz item template (bot JSON + site questions)
Fields: q, options[4], answer (index), expl (≤190 chars, poll-safe), why (2 sentences: doctrine + application), trapnote (1 line technique), round (F/C/M/K/P/I/A/T/X/V/S), trapcat (A-J + K missing-condition + L current-context).

Stem rules: situational, no article-number giveaway, 4 plausible distractors (nearby article / misconception / overbroad rule / half-truth), tempting-but-irrelevant facts encouraged, absolute words only when legally true, A&R max 3-4 per 40, matching max 2 per 40.

## C. Evening set composition (40Q + 5 SI = 45)
F10 foundation + C10 competitive (quiz file) + K3/P2/I2/T3 (hard file) + X5 analytical + V5 current verified-only (ca file) + S5 SI-field duty scenarios (si file). Rounds posted in 7 labelled blocks; two-layer debrief after; diagnosis by round + trap tally.

## D. Pre-publish checklist
[ ] Keys legally audited (answer + explanation both correct)
[ ] Answer positions balanced (~25% each), longest-option ≈25%
[ ] No pending-as-settled, no absolute-word errors
[ ] JS valid (brace check) + headless-browser smoke test, zero console errors
[ ] Local preview approved before any live push
